# Open Source Contribution Plan

## Goal
Make a meaningful contribution to an existing public repository during the eligible hackathon window, alongside the SDE Agent submission.

## Repository selection criteria
- Public repository with an active maintainer community.
- Clear contribution guide, license, tests, and issue tracker.
- A bounded issue aligned with MCP, Agent Skills, developer tooling, documentation, testing, accessibility, or security.
- No need for unauthorized access or private information.
- A realistic chance to produce a reviewable change in the event window.

## Workflow
1. Read license, `CONTRIBUTING`, code of conduct, and CI requirements.
2. Reproduce the issue or verify the documentation gap.
3. Discuss scope with maintainers when needed.
4. Create a focused branch and minimal patch.
5. Add or update tests/docs.
6. Run relevant checks and capture exact output.
7. Submit PR with clear motivation, approach, tests, and limitations.
8. Link the contribution from the SDE Agent demo/evidence index.

## Integrity rules
Do not claim a PR was merged unless the repository confirms it. Do not submit low-quality or unrelated changes only to satisfy a checklist. Follow project license and contribution rules.
